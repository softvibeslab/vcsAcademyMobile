# Smart Agent Journey PRD

## 1. Resumen

`Smart Agent Journey` es una nueva feature mobile-first para aumentar retencion, uso diario y sensacion de progreso dentro del ecosistema Smart Agent.

La feature toma principios de:

- progreso visible
- missions cortas
- feedback inmediato
- streaks
- XP
- desbloqueo progresivo
- avatar guia

y los integra con los modulos ya existentes:

- Smart Agent Core
- Top Producer Roadmap
- Performance Center
- Coaching Room
- Resource Vault

No busca copiar Duolingo.
Busca reinterpretar sus principios de engagement y comportamiento para un producto original orientado a aprendizaje guiado e interaccion diaria.

## 2. Problema

Hoy Smart Agent ya puede:

- responder preguntas
- guiar escenarios
- manejar objeciones
- consumir knowledge base

Pero todavia no crea con suficiente fuerza estos comportamientos:

- retorno diario
- sentido de progreso continuo
- claridad total sobre "que hago hoy"
- deseo de completar una accion mas
- apego emocional al avance

El usuario puede entrar, resolver algo y salir.
Falta una capa de habito.

## 3. Oportunidad

Si convertimos Smart Agent en una experiencia de:

- daily mission
- progreso visible
- recompensas frecuentes
- guidance por avatar
- rutas de avance

podemos mejorar:

- activacion
- retencion
- profundidad de uso
- consistencia de entrenamiento
- consumo de roadmap, coaching y recursos

## 5. Objetivos

## Objetivo principal

Instalar el habito diario de entrar a Smart Agent y completar al menos una mision corta.

## Objetivos de producto

- aumentar usuarios activos diarios
- aumentar dias consecutivos de uso
- aumentar completion rate de actividades
- aumentar consumo de roadmap y recursos
- reducir friccion para comenzar una sesion

## Objetivos UX

- el usuario siempre sabe que hacer despues
- el progreso siempre es visible
- el feedback es inmediato
- cada sesion termina con recompensa o siguiente paso

## 6. No objetivos

- no construir una red social completa
- no construir una tienda compleja en V1
- no meter comparacion agresiva entre usuarios
- no gamificar por encima del valor real
- no reemplazar Smart Agent chat, sino amplificarlo

## 7. North Star Metric

`% de usuarios activos que completan al menos 1 mision diaria`

## Metricas secundarias

- D1 retention
- D7 retention
- average streak length
- mission completion rate
- sessions per active user per day
- next action click rate
- roadmap unlock rate
- avatar interaction rate

## 8. Principios de experiencia

- Mobile first
- Claridad sobre velocidad
- Progreso siempre visible
- Acciones cortas y cerrables
- Feedback inmediato
- Friccion minima
- Recompensas frecuentes pero no vacias
- El avatar aparece cuando aporta valor
- El usuario siempre recibe una recomendacion clara de siguiente paso

## 9. Propuesta de valor

Smart Agent Journey convierte el uso de Smart Agent en una rutina guiada:

1. entras
2. ves tu mision del dia
3. completas una accion corta
4. recibes resultado, XP y celebracion
5. avanzas en un mapa
6. decides si hacer una mas

## 10. Core Loop

1. User opens app
2. Home shows daily mission
3. User starts activity
4. Activity gives instant feedback
5. Result screen awards XP and streak progress
6. Map updates
7. Avatar recommends next step
8. User exits or continues

## 11. Feature Pillars

## A. Daily Mission Layer

La app debe tener una tarea principal diaria visible desde Home.

Requisitos:

- una sola CTA dominante
- dificultad baja o media
- tiempo estimado visible
- relacion clara con progreso

## B. Journey Map

Una ruta visual con nodos, etapas y desbloqueos.

Requisitos:

- progreso secuencial
- estado de cada nodo
- milestones visibles
- lock/unlock claro

## C. Activity Engine

Motor de actividades cortas:

- Ask the Agent prompt challenge
- objection drill
- mini scenario practice
- quick guidance task
- roadmap checkpoint

## D. Result and Reward

Cada actividad debe cerrar con:

- resultado inmediato
- XP ganado
- progreso de nivel
- streak impact
- recomendacion siguiente

## E. Avatar Guide

Un companion visual ligero que:

- explica
- motiva
- felicita
- rescata cuando el usuario abandona

## F. Habit Recovery

Si el usuario rompe ritmo:

- mostrar comeback flow
- reducir friccion de regreso
- dar soft recovery challenge

## 14. Reglas de producto

## XP

- completar actividad: +10 XP base
- primera actividad del dia: +5 bonus
- completar daily mission: +15 bonus
- completar 3 dias seguidos: +10 bonus
- completar 7 dias seguidos: +25 bonus

## Niveles

- nivel sube por acumulado de XP
- cada nivel desbloquea nodos, cosmeticos o badges

## Streak

- cuenta si el usuario completa la mision principal del dia
- si no la completa, streak entra en riesgo
- debe existir una recuperacion suave en una ventana definida

## Unlocks

- por nodo previo completado
- por nivel minimo
- por milestone de consistencia

## Dificultad

- empieza con tareas faciles
- aumenta por complejidad de contexto
- no aumenta por friccion de interfaz

## 20. Riesgos

- over-gamification sin valor real
- demasiadas pantallas en V1
- avatar demasiado intrusivo
- complejidad innecesaria en economia
- mapa demasiado confuso

## Mitigaciones

- mantener V1 pequena
- validar CTA principal en Home
- limitar frecuencia del avatar
- medir time-to-first-mission
- revisar engagement real antes de agregar mas economia

## 22. Decision clave

`Smart Agent Journey` debe construirse como una capa sobre Smart Agent, no como una app separada.

Esa decision permite:

- reutilizar contenido existente
- convertir Core, Roadmap y Vault en experiencias de progreso
- usar data real del producto actual
- acelerar adopcion
