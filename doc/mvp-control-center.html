Planeacion

Ruta de 4 fases

Fase 1

Estabilizacion tecnica

3 a 5 dias para routing, auth, entorno y mocks criticos.

  • Unificar router frontend
  • Corregir organization routes
  • Revisar CORS y variables
  • Definir configuracion real

Fase 2

Cierre de alcance

2 a 3 dias para congelar MVP y sacar ruido del producto.

  • Definir modulos incluidos
  • Ocultar features no MVP
  • Separar backlog post-MVP
  • Simplificar navegacion

Fase 3

Flujos end-to-end

5 a 8 dias para cerrar recorrido real de usuario, admin y branding.

  • Validar login a dashboard
  • Validar cursos y progreso
  • Validar admin usuarios
  • Validar organization y branding

Fase 4

Release MVP

3 a 4 dias para smoke tests, demo reproducible y documentacion final.

  • Completar smoke tests
  • Probar docker compose
  • Unificar guias de deploy
  • Preparar candidate release
