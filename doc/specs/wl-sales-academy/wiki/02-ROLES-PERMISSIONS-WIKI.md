# Roles and Permissions Wiki

## Roles

### Visitor

Public onboarding and login only.

### Sales Representative

Own training, Smart Agent, GoalSheet, roleplays, progress, feedback, and certifications.

### Trainer / Coach

Assigned content, roleplay review, rubric scoring, feedback, readiness recommendations.

### Manager / T.O. Manager

Team progress, Point of Confirmation readiness, T.O. readiness, certification decisions, coaching notes.

### Admin

Users, roles, content, settings, sensitive materials, audit activity, analytics.

## Permission Rule

Every protected action must be enforced on the server.

## Sensitive Material

Sensitive content includes:

- Pricing.
- Fees.
- Incentives.
- Finance.
- Internal worksheets.
- Program documents.
- Rep performance data.
- Manager feedback.

## Audit Events

Audit sensitive resource access, certification actions, role changes, admin content updates, and Smart Agent blocked sensitive requests.
