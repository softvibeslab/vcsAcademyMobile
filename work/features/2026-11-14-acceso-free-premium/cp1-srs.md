## 1. Problem

No hay embudo visitante → registrado → premium ni forma de reservar contenido sin desplegar código.

## 2. Users And Needs

| Usuario | Necesidad |
|---|---|
| Visitante | Probar lo público y registrarse sin invitación |
| Rep gratis | Abrir lo gratuito y activar Premium con un código |
| Rep premium | Acceso completo mientras su plan esté vigente |
| Admin | Decidir el nivel de cada lección/función/recurso, generar códigos, cambiar planes |

## 3. Vision

El admin controla la visibilidad pública, logeada y premium desde un panel; el servidor la hace cumplir.
