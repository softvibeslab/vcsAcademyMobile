# ADR 001 · Nueva entrada web con backend compartido
Estado: adoptada para el alcance solicitado de webapp.

Crear una segunda entrada Vite preserva la app actual y Expo, reutiliza React, iconos y servicios sin duplicar el backend ni migrar datos. La nueva interfaz consume los contratos actuales y mantiene los IDs canónicos de lecciones. Las notas/metas nuevas se guardan localmente por usuario, con etiqueta de dispositivo y exportación; no se integran silenciosamente con otro backend o sistema de sesiones.

Alternativas: sustituir frontend actual complicaría regresiones; integrar el API de Smart Note de otro prototipo requeriría un contrato de identidad que no existe. Consecuencia: notas/metas no se sincronizan entre dispositivos; ese trabajo queda separado.
