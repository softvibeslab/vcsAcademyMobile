# VCSA Academy

WL | White Label Sales Academy is a mobile-first sales training, roleplay, Smart Agent, GoalSheet, manager review, and certification platform.

## Local Commands

```bash
npm run dev:backend
npm run dev:web
npm run dev:mobile
npm run check
```

The current implementation is the first E2E vertical slice for Sprints 1-7:

- Monorepo structure.
- Shared domain rules.
- FastAPI backend.
- React webapp.
- Expo mobile app.
- Rep dashboard, Blueprint, GoalSheet, Roleplay, Smart Agent, and manager review API flows.
